# Backend Lab

Laboratorio personal para aprender desarrollo backend desde los fundamentos hasta el despliegue y la operación de servicios.

## Objetivos

- Aprender Python y desarrollo de APIs con FastAPI.
- Trabajar con PostgreSQL y SQLAlchemy.
- Aplicar arquitectura hexagonal y testing.
- Administrar un servidor Linux.
- Aprender Docker, CI/CD y despliegues.
- Explorar más adelante microservicios e infraestructura para IA y MCP.
