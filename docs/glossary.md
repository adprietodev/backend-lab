# Glossary

| Term | Definición |
|---|---|
| PATH | Variable de entorno que contiene las rutas donde se buscan ejecutables. |
| Executable | Archivo que el sistema puede ejecutar como programa. |
| Symbolic Link | Enlace que apunta a otra ruta del sistema de archivos. |
| Shell | Programa que interpreta comandos, como zsh. |
| Interpreter | Programa que ejecuta código de un lenguaje, como Python. |
| Repository | Conjunto de archivos y su historial de versiones gestionados mediante Git. |
| Remote | Referencia a un repositorio alojado en otra ubicación. |
| Branch | Línea de desarrollo dentro del historial de Git. |
| Commit | Registro de un conjunto de cambios en el historial de Git. |
